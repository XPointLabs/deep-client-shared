# S05 — authenticated expired Initial, source checkpoint

Normative owner:
[DR-0138](../../../docs/survival-program/decisions/DR-0138-expired-authenticated-initial-disposal.md).
This is a Shared implementation/evidence mapping, not a second protocol rule.

The owned mailbox receiver uses Protocol's closed live/terminal preparation.
Terminal custody uses the existing native receiver transaction and protected
checkpoint, without registering a mutable messaging source. ACK reconstructs
that native receipt independently; service selection metadata is not authority.
Existing live source import and key retirement explicitly reject terminal
records. No account, node or original pending intent was reset.

Initial focused batch:10 PASS/native0/0skip, Windows PowerShell5.1 and SDK10.0.301,
with no compiler diagnostics. It includes five terminal/crash/lost-ACK cases,
time-uncertainty refusal, two existing live contact/message flows and two
captured-final-page expiry continuations. The fixture uses actual authenticated
PQ Initials, encrypted storage, native atomic consumption and signed in-process
issuer/terminal responses. It is not a socket/device delivery claim.

Final review added a post-preparation live lifetime fence, an explicit native
retirement refusal, avoided redundant own network acquisition for fresh Initials,
and tightened the live-alias negative assertion. The next focused batch also
checks missing/changed native terminal proof and a separate current contact on
the same retained accounts after disposal. Final focused batch:12 PASS/native0,
0skip and no compiler diagnostics. The same retained accounts accepted a
separate current contact after terminal disposal and an empty next poll; both
native SQL proof-corruption cases rejected before any ACK. This is focused
source evidence, not full/package or physical acceptance.

Protocol's first focused surface-only run passed7 cases/native0. Correcting the
filter to actual partial-class method names (rather than source filenames)
qualified22 cases/native0/0skip, including current/retained contact endpoint
checks, claim crypto/promotion and the exact closed public surface. No runtime
change or test assertion was removed to obtain that result.

Full source/package/frozen registry qualification and matching Windows/Android
installation, real receive/ACK/next poll and subsequent messages/files/groups
remain open. S05 and physical acceptance remain unaccepted; no release/main.
