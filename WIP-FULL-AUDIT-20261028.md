# P1 full-audit equivalence outline — implementation review only

No runtime acceptance or ordinary admission follows from this outline. The small/medium independent test reference still constructs the literal tree from all qualified observations. Production full audit uses constant-memory source replay and canonical-tree traversal; ordinary reads use neither lifetime traversal.

1. Join actual catalog/key/registration/bootstrap/floor/immutable history/archive and the exact SQL mirror. Verify all cipher pages and the immutable source checkpoint. Full source traversal uses actual table cells/rowids (`NOT INDEXED`) and the existing native payload/transition checks. Qualify outgoing DMC2 against the independent protected authored roots, exact application originals and counters through the paired fresh physical-read segment.
2. DFS every node named by the actual protected Patricia root. Recompute scoped node hashes, enforce canonical prefix/split/child relations and typed selector/key/value framing, and reject every missing node. The stack is bounded by 257; no lifetime visited-node dictionary is needed because strictly increasing split bits and disjoint prefixes exclude a valid cycle or shared subtree across disjoint branches. Decode every reference, bind its actual rowid/columns/metadata hash/payload and scope, and independently derive the leaf's typed selector. Maintain checked per-family leaf counts.
3. Independently stream all archived originals in ordinal order. Replay native/authored semantics with only the reducer's fixed reference set and a bounded source batch. For each source fact require exact membership/value in the actual canonical tree. Count a family key only when this stream encounters the unique reference selected by that value; do not count a real row merely because a leaf points to it.

| F1 | Every direction1–4 operation requires its exact Ref88. Count each actual source event once. |

Require the exact closure-hash leaf and its consent/predecessor/sequence value. Count only when the emitted qualified reference equals the selected first ref. Monotonic completed-route generations make promoted closure keys unique; duplicates are checked by the full replay and cannot increment the count. A DFS leaf pointing to a real but unqualified row has no corresponding source count and rejects. |
| F6 | Every incoming kind derives logical/device selector. First ref must be no later than every occurrence; a second distinct row is required no later than every later row, even for identical event bytes. Count only the selected first ref. |

4. The DFS also validates each optional second witness against its own actual source, typed selector and exact event hash where applicable. Per-source comparisons prove earliest first/second selection. The required exact memberships prove that no qualified source fact is omitted. Equality of each per-family DFS count to its independently counted source facts then excludes extra leaves; counts alone never prove membership, values, eligibility or uniqueness. F1/F3 counts also equal the independently streamed archive event count.
5. Reproduce reducer960 independently from the complete qualified source stream, including initial metadata/policies, actual consent, own/peer head and previous, first fault and maximum authenticated incoming DPE2 epoch with selected source reference. Compare exact reducer bytes/digest/basis against both the actual SQL reducer and protected root. Compare the streamed event count with archive count. Canonical Patricia shape is unique for the fully verified typed key/value set, so verified complete leaf equivalence plus canonical DFS proves the same scoped root commitment as literal reconstruction.
6. Basis0 grants no archived initial fact: root/reducer/trie are scoped empties and all import/activation/data stay in the bounded suffix. Active basis>=2 with count0 still replays the actual initial singleton: initial hash and role-appropriate sequence2 head are required; only the eligible peer-Hello F5 may exist. Consent, fault and epoch remain absent until an actual archived qualifying event. These branches have exact family counts, not a generic positive-count assumption.
7. Replay and verify every remaining suffix transition (including import, activation and terminal latch) against the moving archive basis and actual stable floor. Latch stays in the suffix and cannot become an archive basis. Digest2 binds actual archive608, basis188, floor188 and every suffix ordinal/metadata header. No current authority or source permission comes from any archived fact.
